# TherapistDesk

## Цел

TherapistDesk е уеб приложение за управление на терапевтична практика.

Основните цели са:

- управление на клиенти;
- календар и срещи;
- повтарящи се срещи;
- автоматични напомняния;
- клиентски достъп без регистрация;
- бележки към срещите;
- push известия;
- бъдеща синхронизация между устройства.

---

## Основни принципи

- PostgreSQL е основната база данни.
- Всички промени по базата се правят чрез Prisma Migrate.
- Не се използва `prisma db push` при разработката.
- Всяка промяна по schema.prisma се придружава от нова миграция.
- Всеки по-голям етап завършва с Git commit.
